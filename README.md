# WASH training landscape (demo)

Interactive directory of WASH trainings and recorded webinars for the WASH Circuit Riders Community of Practice ([washcircuitriders.org](https://washcircuitriders.org)), compiled by the Water Institute at UNC (data current to October 2026).

This is a review demo. `index.html` is self-contained: the data is embedded in the page.

- Full page: `index.html`
- Audience table and directory only: `index.html?view=dir`
- Webinar library only: `index.html?view=web`
